Running a two-person studio generates exactly the coordination problem you'd expect: two founders, three products, and no shared place to see what's moving. The ACEU Command Dashboard is the internal tool that fixes it — projects, tasks, a resource Library, an activity feed, and a daily Bible verse, because the studio starts its day there.

The architecture is deliberately small. It's a single-file app — vanilla JavaScript with Tailwind — that works entirely from `localStorage` offline, with JSON export and import as the permanent escape hatch. Cloud sync is one private `dashboard_state` row in Supabase's free tier, guarded by row-level security that allowlists exactly three emails: both founders and the studio inbox. No public signup, no roles, no team features. Two people do not need a permissions system; they need the same state on both laptops.

## Small tool, real product care

The design pass treats it like a personal Notion rather than an admin panel: warm Paper and Dusk themes routed through CSS variables with an OS-preference first run and no flash of the wrong theme, Geist and Instrument Serif type, hairline borders instead of shadows, a time-of-day greeting, and emoji project icons. Tasks run on an HTML5 drag-and-drop kanban with due-date chips and a search toolbar. The Library holds links, form URLs, and file pointers with tabs, search, and sort. Everything is keyboard-first — `1`–`6` switch views, `n` logs a task, `t` flips the theme.

It installs as a PWA with an offline shell, ships CSP and HSTS headers on Vercel, and soft-deletes come with a five-second undo toast.

For an internal tool it is embarrassingly well tested: 53 pure unit tests, 20 payload guards, 46 Playwright smoke checks, and a 135-check in-app harness behind `?test=1`, plus theme-verification and screenshot-sweep scripts. It has been live and in daily founder use since August 2026.
