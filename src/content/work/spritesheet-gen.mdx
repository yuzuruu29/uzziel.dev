SpriteSheet Gen is a browser tool that generates spritesheets from individual sprite images. Upload your frames, arrange them in a grid, adjust padding and layout, and export the combined sheet as a single PNG. Everything runs client-side on an HTML Canvas — no uploads, no server, no install.

I built it because Aseprite's export pipeline did not always produce the exact grid layout I needed for Godot tilemaps, and every online spritesheet tool had a file size limit or an aggressive watermark. This one lives in a single HTML file with embedded CSS and JS. Open it, drop your sprites, click export.

The tool supports configurable columns, cell padding, and background color. Output preserves the original sprite resolution without recompression. It is not a commercial product — it is the tool I reach for when Aseprite's spritesheet wizard is overkill and I just need a clean grid of my 16×16 tiles in one image.
