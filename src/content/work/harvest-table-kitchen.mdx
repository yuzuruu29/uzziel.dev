Harvest Table Kitchen is a fictional portfolio sample for a small food business handling weekly meals, party trays, and catering inquiries.

The sample focuses on replacing lost DMs and phone calls with a structured order path. It includes menu highlights, preorder steps, catering details, pickup and delivery notes, lead-time guidance, dietary information, FAQ accordion, inquiry CTA, order form, and a thank-you state.

The technical build is static and mobile-first, using vanilla JavaScript only for the navigation, FAQ, and form state.
