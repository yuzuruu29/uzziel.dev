The Philippine Government Hub is a directory app for government services — SSS, Pag-IBIG, PhilHealth, DFA passport appointments, LTO, PSA, BIR, DSWD, and more. You search or browse, get the official website, office hours, requirements, fees, and a step-by-step guide for each service. No login, no ads, no sponsored results.

The data lives in static JSON files under `data/`. Fuse.js powers the search with fuzzy matching — misspell "Pag-IBIG" and it still finds the right entry. Tailwind handles the responsive layout, Lucide icons fill the visual gaps. Mobile-first throughout.

I built it because every time I needed to renew a government document I ended up hopping between three poorly maintained websites and a Facebook page from 2019. The hub is structured the way I wished those sites were: one search bar, clear categories, no carousels. TypeScript strict keeps the JSON data shaped correctly as the dataset grows.

Still in flight: a more complete service catalog, a crowdsource corrections path, and a PWA install prompt so it lives on a phone home screen like an app should.
