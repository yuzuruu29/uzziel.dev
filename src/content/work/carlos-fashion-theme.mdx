Carlos Fashion Theme is a custom WordPress theme built from the template hierarchy up — no page builders, no premium frameworks, no "just install Elementor." The theme covers the full set of WordPress template files: `header.php`, `footer.php`, `index.php`, `front-page.php`, `single.php`, `page.php`, `archive.php`, `sidebar.php`, and a `template-parts/` directory for reusable component includes.

The design follows a minimal fashion-blog aesthetic: large hero imagery, clean product grids, a single-column article layout with featured image support, and a color palette leaning neutral with accent tones for callouts and CTAs. `functions.php` registers navigation menus, widget areas, theme support for post thumbnails and custom logos, and enqueues assets with version hashing.

I built it to prove I could ship a custom WordPress theme that does not rely on commercial plugins or drag-and-drop interfaces — a skill that matters for clients who already have a WordPress install and need a tailored front end without switching platforms. The theme is ready for child-theme customization or direct deployment.
