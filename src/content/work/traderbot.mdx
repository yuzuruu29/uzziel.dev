TraderBot is a trading signal system I run through HiveMind instead of a standalone Telegram bot. Market data agents fetch OHLCV from Binance (crypto) or Yahoo Finance (stocks), technical analysis agents score RSI, MACD, EMA crossover, volume, and Bollinger bands, a risk agent applies position sizing against a PHP capital floor, and synthesis outputs BUY/SELL/HOLD with confidence â€” every run logged as Markdown in the Obsidian vault under `02-Projects/traderbot/signals/`.

The June 2026 sprint added what backtests actually need: trend regime filters, threshold sweep mode, and multi-timeframe input to the consensus bridge. A 30-day BTCUSDT backtest now writes a full report to the vault â€” win rate, profit factor, Sharpe, monthly breakdown, best/worst trade â€” so I can compare signal changes across commits instead of guessing from one screenshot.
